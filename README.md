# 💳 Banking Backend System

A RESTful banking backend that simulates core banking operations such as user authentication, account management, and secure money transfers using a ledger-based architecture.

## ✨ Highlights

- Secure Authentication using JWT
- Account Management
- Money Transfer with Transaction Safety
- Ledger-Based Balance Calculation
- Email Notifications

## 🛠 Tech Stack

- **Backend:** Node.js, Express.js
- **Database:** MongoDB, Mongoose
- **Authentication:** JWT, bcrypt
- **Deployment:** Render

## 📦 Getting Started

Clone the repository

```bash
git clone <repository-url>
cd BankingSystemBackend
```

Install dependencies

```bash
npm install
```

Create a `.env` file

```env
MONGO_URI=
JWT_SECRET=

EMAIL_USER=
CLIENT_ID=
CLIENT_SECRET=
REFRESH_TOKEN=
```

Start the server

```bash
npm start
```

Server runs on:

```
http://localhost:3000
```
